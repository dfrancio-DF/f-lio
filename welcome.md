# Um pouco de calma para ler.

Bem-vindo ao **Fólio**, seu espaço para ler Markdown. Abra um arquivo, encontre uma posição confortável e deixe o conteúdo ocupar o centro.

> Boas ideias merecem uma página sem distrações.

## O essencial, bem cuidado

Uma interface discreta, inspirada na clareza do Outline. Tipografia confortável, espaço para respirar e só o que você precisa por perto.

- **Abra do seu jeito** — arraste um `.md` para a janela, use o botão Abrir arquivo ou pressione `Ctrl + O`.
- **Encontre o caminho** — navegue pelas seções usando o índice à direita.
- **Continue escrevendo** — salve no seu editor e a leitura se atualiza automaticamente.
- **Edite quando quiser** — abra um documento e clique em **Editar** para alterar o Markdown aqui mesmo. Salve e volte à leitura.
- **Fique à vontade** — alterne o tema, ajuste o tamanho do texto ou entre no modo foco.

## Feito para o seu Markdown

Títulos, listas, tabelas, links, imagens locais e blocos de código. Tudo com uma apresentação consistente, sem precisar de internet.

```python
from pathlib import Path

def uma_boa_leitura(arquivo):
    texto = Path(arquivo).read_text()
    return texto, "um pouco mais de clareza"
```

## Um atalho para cada momento

| Atalho | Ação |
| --- | --- |
| `Ctrl + O` | Abrir arquivo |
| `Ctrl + E` | Editar / voltar à leitura |
| `Ctrl + S` / `Ctrl + Shift + S` | Salvar / salvar como, no editor |
| `Ctrl + Z` / `Ctrl + Shift + Z` | Desfazer / refazer, no editor |
| `Ctrl + F` | Buscar no documento |
| `Ctrl + Shift + F` | Entrar ou sair do modo foco |
| `Ctrl + +` / `Ctrl + -` | Ajustar tamanho do texto |
| `Ctrl + 0` | Restaurar tamanho |
| `Ctrl + R` | Recarregar arquivo |
| `Esc` | Fechar busca ou sair do foco |
